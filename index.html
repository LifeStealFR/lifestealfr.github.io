PORTAIL OFFICIEL — VITRINE & DOCUMENTATION OCT. 2026

Nous concevons des outils communautaires, des bots Discord et des architectures web modernes.

lifestealmc.fr est le portail officiel et la vitrine de nos projets de développement. Nous y centralisons notre studio d'outils web, nos bots Discord — dont Kurotsuki Studio —, notre API Gateway et notre infrastructure. Chaque projet partage le même socle d'exigence : code maintenable, sécurité by design, observabilité et documentation exploitable en production.

Notre stack de prédilection repose sur Node.js 20 LTS pour les services temps réel et les workers, Next.js (App Router) pour les applications web et les dashboards, des API HTTP/REST et WebSocket versionnées et authentifiées, le tout opéré sur Linux (Debian/Ubuntu) derrière un reverse proxy Nginx, avec conteneurisation Docker, supervision de latence et sauvegardes automatisées. Ce portail sert de hub : il présente les projets, redirige vers les applications hébergées sur nos sous-domaines et publie la documentation technique qui les accompagne.

Projet phare — Bot Discord

Kurotsuki Studio

Bot Discord moderne et plateforme de gestion de serveurs : réactions animées et utilitaires communautaires, installation au choix sur un compte utilisateur ou sur un serveur entier, interface multilingue, statistiques et classements, suite de sécurité avec détection anti-raid et anti-phishing, synthèse intelligente des tickets et commandes d'audit.

  • Gestion de serveurs : rôles, salons d'accueil, messages de bienvenue et configuration guidée
  • Sécurité : vérification à l'arrivée, détection de comptes suspects et journalisation des actions sensibles
  • Utilitaires : réactions, sondages, rappels, messages programmés et exports de données
  • Disponibilité 24/7, mises à jour continues et support dédié

Modération automatisée

Sentinelle de modération

Pipeline de modération programmable : listes de règles versionnées, files d'examen manuel, actions graduées (avertissement, mute temporaire, bannissement) et journal d'audit horodaté. Chaque décision automatique est traçable et réversible, avec seuils anti-faux-positifs configurables par communauté.

API · Interopérabilité

API Gateway unifiée

Point d'entrée unique devant nos micro-services : authentification par clés d'API à périmètre restreint, quotas par client, validation stricte des payloads, réponses d'erreur normalisées et journalisation centralisée. Les intégrations tierces consomment une seule base d'URL versionnée au lieu de N services disparates.
